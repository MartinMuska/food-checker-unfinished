# My Early Code Project

This is my first attempt at writing a more complex program. The project was designed for my personal use in managing and searching for groceries. It is an unfinished project, and if I were to do it today, I would approach it differently.

## Unfinished Features

- Food Checker – Displays food status: good, expired (next day), close to expiration (three days before), or approaching expiration (one week before).
- Food Search – Shows tax information and expiration date.
- Recipe Search – Allows searching for recipes based on available ingredients.
